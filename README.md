# World Cup Tiesheet

A prediction bracket for the 2026 FIFA World Cup knockout stage.

Users sign in with Google, pick the country they think will win the whole tournament,
then fill in a 32-team knockout bracket. Points are awarded when their picks match
real results. The leaderboard is public.

## Scoring (proposed — to be confirmed)

- Correct R32 pick: **+2**
- Correct R16 / QF / SF / Final pick: **+3** each
- Bonus if predicted champion actually wins: **+10**

## Stack

- Frontend: vanilla HTML / CSS / JS (static)
- Backend: Supabase (Postgres + Auth)
- Hosting: Vercel
